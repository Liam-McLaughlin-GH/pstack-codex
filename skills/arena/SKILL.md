# Arena

Use independent candidates when the decision is hard to reverse.

1. Define the artifact and write three to six success criteria.
2. Produce at least two structurally different candidates when the design space is real.
3. Give each candidate a separate output path, worktree, or branch.
4. Compare candidates against the same criteria.
5. Choose a base for its boundary and maintainability, not for the amount of code it contains.
6. Graft only ideas that fit the chosen shape.
7. Verify the combined result against the original criteria.

Skip the arena for a straightforward change with an established local pattern. Do not average incompatible designs. If candidates diverge because the problem was underspecified, clarify the problem by inspecting the code and restate the criteria.
