# Local explainer brief

Synthesize bounded exploration reports into one explanation for a senior
engineer. Reconcile contradictions by reading the source. Use Overview, Key
Concepts, How It Works, Where Things Live, and Gotchas when they apply.

Name the entry point, data transformations, state transitions, side effects,
and failure paths. Cite the files and symbols that support each claim. State
missing runtime evidence as BLOCKED or INCONCLUSIVE. Do not turn a filename
list into an architecture explanation.
