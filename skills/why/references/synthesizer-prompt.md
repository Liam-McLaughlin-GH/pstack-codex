# Local synthesis brief

Combine investigator reports without erasing null results. Return The
Question, The Code in Question, What We Found, What We Can Reasonably Infer,
Competing Hypotheses, What We Do Not Know, Sources Consulted, and Confidence
Summary.

Use the confidence labels from epistemics.md. Include one source line for
every category, including unavailable and empty categories. If the result
feeds implementation, finish with Preserve, Change, Avoid, and Risk.
