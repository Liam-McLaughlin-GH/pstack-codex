# Confidence and evidence rules

Use four labels:

- Observed: directly present in source, history, a supplied artifact, or a
  command result.
- Strongly supported: multiple independent observations point to the same
  explanation.
- Inferred: a plausible explanation that fits the observations but is not
  recorded directly.
- Unknown: the searched evidence does not answer the question.

Keep the label beside the claim. Say what evidence would move an inference to
strong support or disprove it. An empty source category is a finding.
