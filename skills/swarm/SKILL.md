# Swarm

Parallel work only helps when each unit has a clear boundary.

1. Define the complete outcome and the shared contract.
2. Partition by files, symbols, scenarios, or questions so units do not write the same state.
3. Give each unit one outcome, one evidence requirement, and one output path.
4. Run independent units in parallel when the available Codex session supports it.
5. Review every result against the shared contract.
6. Combine the results in one place and run an integration check.

Do not parallelize dependent edits. Do not trust a summary without opening the changed files or evidence it names.
